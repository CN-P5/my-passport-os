# rc.59 能力迁移（小智 MCP / 网易云 / 备忘 / 清单 / AI 热点 / 表情动画）

日期：2026-11-16　分支：`rc59-spike`（worktree：`_work/rc59-spike`）
上游：`origin/main` = `5101891`（rc.59 candidate），基点 `b70879b`（rc.56）

## Goal

把上游 rc.59 的功能面整体并入本分支，同时保留本地已有改造（天气应用、首页亮暗自适应/底图/人像预设、手机设置局域网直连、构建脚本等）。

验收（用户可见）：
1. 任意界面**双击 OK** 进入小智；熄灭屏幕后双击也能唤醒并进入。
2. 对小智说"音量调到 40""亮度 60%""打开收音机""播放临沂广播""开始番茄钟"能真实执行。
3. 新增应用可用：网易云音乐、备忘提醒、文字清单、AI 热点。
4. 小智有表情动画/等级 UI。
5. 设置类工具：亮暗模式、主题可被小智切换。
6. 既有功能不回归：首页布局/亮暗/底图/人像、天气页缓存刷新、手机设置局域网 IP 访问、9 个原有应用。

## 架构与迁移策略

- **不手工逐文件移植，改为合并 `origin/main`**：48 个新文件（`apps/netease`、`apps/reminders`、`apps/lists`、`apps/aihot`、`device_control*`、`voice_intent*`、`xiaozhi_face`、`ok_gesture.h` 等）无冲突自动入。
- 14 个冲突文件按"保留本地体验 + 采纳上游功能"的原则逐个合并；冲突面已实测（29 个冲突块）。
- 上游仍保留 game/muse 两个应用，而本地已下架：app 枚举保留 id，注册表与 key 表排除，MCP `application.open` 的 key 表同步裁剪。

## Baseline / 兼容边界

- 新增 `BTN_EVT_DOUBLE`，所有应用 `on_key` 默认忽略；**单击 OK 会等 180ms 双击窗口**——游戏/番茄钟/设置手感必须回归。
- app id 编号与上游不同（本地有 `APP_ID_WEATHER`），禁止 cherry-pick 贴 id 的代码。
- 新增应用会增大固件：预算余量约 950 KB，需在合并后复核 `verify_firmware.py`。
- 分区不变（4 MB factory），NVS 命名空间新增项需检查是否与本地 `system_prefs` 冲突。
